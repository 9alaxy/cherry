# 峰值显存对比实验规范（冻结版）

## 方法 ID 对照表

- `Berry` -> `micro_batch_train_berry.py --selection-method Berry`
- `Betty` -> `Betty.py --selection-method REG --re-partition-method REG`
- `DGL_random` -> `micro_batch_train_berry.py --selection-method Random`
- `DGL_metis` -> `micro_batch_train_berry.py --selection-method Metis`

## 范围与主指标

- 主结论只使用峰值显存（GB）。
- 训练精度、训练时间只做附录日志，不进入主图结论。
- 输出图共 5 张（每个数据集 1 张），每图 4 方法 × 3 模型柱状对比。

## 硬件与运行约束

- 仅使用 RTX 3090。
- 默认 `DEVICE_NUMBER=1`。
- 手工执行训练时必须显式携带 `--device-number 1`（除非你手工覆盖）。
- 每次运行必须导出双日志：
  - 主训练日志（stdout/stderr）
  - `nvidia-smi` 周期采样日志

## 固定参数

- `num-batch=8`
- 层数固定 3 层。
- 模型配置：
  - SAGE: hidden=256, aggre=pool
  - GCN: hidden=256
  - GAT: hidden=128, heads=4
- 数据集 fan-out（本轮固定）：`10,25,30`。

## 目录规范

- 脚本目录：`/workspace/Cherry/Evaluation/berry/peak_mem_exp`
- 日志目录：`/workspace/Cherry/Evaluation/berry/peak_mem_exp/log`
- 失败清单：`fail_manifest_*.csv`
- 汇总表：`peak_memory_results.csv`
- 图目录：`log/plots/`

## 执行顺序

1. `run_peak_memory_experiment.py --phase smoke`
2. `run_peak_memory_experiment.py --phase full`
3. `collect_peak_memory_results.py`
4. `plot_peak_memory.py`

## 结果字段

汇总表最少包含：

- `dataset, model, method, seed`
- `peak_mem_gb_framework`
- `peak_mem_gb_nvsmi`
- `status`

失败任务必须在 `fail_manifest` 中可追溯（退出码、是否 OOM、是否超时、日志路径）。
